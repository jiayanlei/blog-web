# Personal Site Direction

## 当前共识

- 这个站不应该太像简历。
- 它更像一种个人记录：记录成长、项目、练习、生活、想法和阶段。
- 可以有一点诗意和个人气质，但不要变成特效展示站。
- 当前版本可以先普通一点，后续再慢慢调整细节。
- 不做文章系统，不做路由式博客。
- 保留左侧节点展示，不使用 React Router。

## 左侧节点

当前节点定为：

- 起点
- 关于
- 技术
- 项目
- 生活
- 寻找

要求：

- 左侧节点导航需要一直固定可见。
- 不能滑下去之后找不到导航。
- 节点是页面主题的一部分，不只是普通导航。

## 文案倾向

- 不要写得太正式。
- 第一屏不要使用“但我仍然选择，把每一次练习写进代码里。”
- 保留“或许，我们只是差了一些运气和机会。”这类有个人气质的表达。
- 起点介绍保留“或许，我们只是差了一些运气和机会。”作为核心开场。
- 关于区更像一段有诗意的自述，可以委婉地表达“我不是一个已经完成的人，我只是把一些想法写下来，把一些问题拆开，把一些页面和系统慢慢做出来。”
- 联系区不要像正式合作邀请，更像自然地“寻找”和“聊聊”。
- 寻找区可以写：“如果你也在构建些什么，可以来聊聊。”
- 技术区不要像简历技能标签，倾向叫“常用工具”。
- 项目区不要像简历项目，改成“项目切片”。
- 项目只记录“当时想解决什么”和“我做了哪部分”，不要写“留下了什么经验”。

## 主题倾向

更接近：

- 一个程序员的时间记录
- 未完成的作品集
- 练习、构建、项目和阶段的切片

不接近：

- 传统求职简历页
- 正式企业风作品集
- 博客文章系统
- 大量动画或背景特效页面

## 视觉氛围

- 整体像安静的深色记录本，但不能变成传统日志页。
- 可以有亮点，但亮点应该精致、克制，不依赖大背景和强特效。
- 颜色先采用深灰黑背景、柔和灰白文字、浅青重点色、旧金辅助色。
- 左侧节点改成类似时间锚点：固定可见、小圆点、淡竖线、hover 轻微变亮。
- 页面区块不做大卡片套大卡片，依靠留白、细线和排版建立层次。
- 动效可以有，但非常少，要精致：hover、边框、轻微位移即可。
- 字体使用系统中文字体，保持干净，不刻意文艺。
- 生活区可以做成小记录条目，像正在发生的片段，而不是兴趣列表。

## 后续待沟通

- 第一屏标题和副标题的语气
- “记录感”如何体现在页面结构里
- 项目展示是否要像时间线/片段，而不是普通项目卡片
- 技术区如何体现“常用工具”
- 生活区应该包含：正在学 AI 哪方面、对 AI 的看法、vibe coding 在练什么、还没变成项目的想法
- 颜色、留白、字体和细节装饰
